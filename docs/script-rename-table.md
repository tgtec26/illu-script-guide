# 스크립트 이름 변경 대조표 (2026-10-10)

접두사(`Object_`, `Text_` …)를 떼고 한글 이름으로 바꾼 기록이다. 폴더는 그대로이고 `00_세팅/setup.jsx`는 이름을 바꾸지 않았다.
새 이름은 이름 표(스프레드시트)에서 사용자가 확정했다. 옛 파일명으로 이 저장소의 지난 기록(`git log --follow`)이나 `docs/superpowers`의 옛 문서를 찾을 때 쓴다.

- **저장 키(`PREF_KEY`)는 바꾸지 않았다.** 예: 대류 스크립트의 저장 키는 계속 `Object_Convection/settings`다(바꾸면 사용자가 저장한 옵션이 사라진다).
- 홈페이지 항목 id, 탭 id는 그대로다.
