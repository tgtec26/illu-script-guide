# 선 두께 컨트롤 점검 (2026-10-14)

범위: `스크립트/` 전체에서 선 두께를 조절하는 행을 찾았다. 각 행이 실제로 어떤 선의 `strokeWidth`에 들어가는지 코드로 따라가 확인했다(읽기만 함). 줄 번호는 바뀌므로 탭 이름과 함수 이름으로 찾는다.

판정 기준: 한 값이 **보이는 역할이 같은 선**을 바꾸면(다각형의 모든 변, 축과 축 화살촉) 일괄로 둔다. **역할이 다른 선**을 함께 바꾸면 분리를 권한다. 역할이 다른 선은 축과 눈금, 그래프와 점선 보조선, 도형 선과 각·직각 표시, 회색 모눈과 점선 같은 경우다.

이미 고친 것(커밋 2da4ff6): 중학교 수학의 **수직선**(축·눈금·해 선)과 **좌표평면**(축·눈금 분리, 보조선 툴팁).

## 1. 효과가 없는 행 (버그)

| 스크립트 / 탭 | 행 | 원인 |
|---|---|---|
| 기하 / 3D 입체 | 선 두께 패널의 축·보조선 | 그리는 선은 `main`·`dashed`뿐이라 두 값이 쓰이지 않는다. 실제로 동작하는 두께 행은 "시점 · 크기" 패널에 있다 |
| 역학 장치 / 물체 A·B | 보조선(wGuide) | `drawBlocks`가 값을 쓰지 않는다 |
| 주기율표 | 선 두께 | 기본값(테두리 꺼짐)에서는 효과가 없는데 행이 비활성화되지 않는다 |
| 에너지 준위 | 스펙트럼 띠 겉·스펙트럼선 | 스펙트럼을 끄면 효과가 없다 |
| 중학교 수학 / 작도 | 그래프 | 외접원·내접원이 없으면(선분·각 모드) 효과가 없다 |
| 중학교 수학 / 좌표평면 | 보조선 | 버그는 아니다. 축까지 점선·점근선·y=x·모눈이 없으면 바뀌는 것이 없다(툴팁으로 안내함) |

## 2. 축과 눈금이 한 값 (분리 권장)

- 중학교 수학: 통계, 실생활 그래프 (수직선·좌표평면은 고침)
- 공통수학: 이차함수, 도형의 이동, 원과 직선, 부등식 영역, 유리·무리함수
- 기하: 이차곡선, 이차곡선 접선, 벡터
- 수학1: 지수·로그, 삼각함수, 단위원과 그래프, 수열
- 수학2: 구간별 함수, 증감·극값, 미적분, 속도와 거리
- 확률과 통계: 확률분포
- 01_도형: H-R도, 반감기 그래프, 자기장 영역과 고리, 그래프·표 / 복사, 역학 / 수평 던지기

## 3. 그 밖에 역할이 다른 선이 한 값인 곳

**보조선(점선)과 회색 모눈**: 공통수학 이차함수·도형의 이동·원과 직선·유리·무리함수, 기하 이차곡선·이차곡선 접선·벡터, 수학1 지수·로그·삼각함수, 수학2 구간별 함수·증감·극값·미적분·속도와 거리, 중학교 수학 좌표평면·실생활 그래프. 공통수학 부등식 영역은 모눈이 **축** 값을 따른다.

**보조선(점선)과 실선 표시(각 호·직각·같은 길이 눈금·치수선)**: 공통수학 원과 직선, 기하 도형·벡터·공간도형, 수학1 삼각함수·단위원·단위원과 그래프·삼각형, 수학2 증감·극값(수평 접선), 중학교 수학 원·색칠한 부분·도형 문제, 작도(점선과 컴퍼스 호).

**축 값에 축과 무관한 선이 섞인 곳**:

| 스크립트 / 탭 | 축 값에 섞인 선 |
|---|---|
| 기하 / 이차곡선 | 초점 선분 |
| 기하 / 벡터 | 보조 벡터 ka⃗·lb⃗, 정사영 |
| 수학1 / 수열 | 계차 V선 |
| 수학2 / 증감·극값 | 증감표 |
| 수학2 / 미적분 | 구분구적 직사각형 테두리 |
| 확률과 통계 / 확률분포 | 막대 테두리 |
| 중학교 수학 / 통계 | 히스토그램 막대 테두리 |
| 에너지 준위 | 축이 전이 화살표 행 값을 따름 |

**과학 도식(01_도형)에서 축·점선·화살표가 한 값인 곳**: 반응 경로 에너지 도표(축·점선·Ea/ΔH 화살표), 상평형 그림(축·점선), 반감기 그래프(축·점선), 자기장 영역과 고리(영역 테두리·×·축·화살표), 화학 전지(도선·계기·전자 화살표), 역학 장치(실·속도/힘 화살표), 파동의 간섭(기준선과 파동).

**값 하나가 거의 전부**: 그래프·표 / 복사(곡선·축·눈금·영역 화살표), 역학 / 수평 던지기(궤적·축·점선·화살표·공 테두리), 확률과 통계 / 경우의 수(탁자·좌석·화살표·격자·×), 그래프·표 / 모델(곡선과 점선 안내선).

## 4. 선 두께 행이 "선 두께" 패널 밖에 있는 곳

수학 묶음과 폼 엔진(창 하나에 "선 두께" 패널이 있는 스크립트)에서 벗어난 것:

| 스크립트 / 탭 | 행 | 있는 패널 |
|---|---|---|
| 중학교 수학 / 표기 | 선 두께(0.1~1, 단계 0.05) | 크기 |
| 중학교 수학 / 표기·작도·원 | "도형 선 0.8pt로 맞춤" 체크 | 크기 / 표시 / 그릴 것 |
| 기하 / 3D 입체 | 선 두께(실제로 동작하는 행) | 시점 · 크기 |
| 수학2 / 단면이 도형인 입체 | 선 두께 | 모양 |

"선 두께" 패널이 없는 과학 스크립트는 두께 행이 개체 패널에 들어 있다. 개체 단위로 묶었다고 볼 수도 있지만, 한 창 안에서 위치가 제각각이다.

| 스크립트 / 탭 | 행 → 있는 패널 |
|---|---|
| 그래프·표 / 복사 | 선 두께 → 곡선(축까지 바꿈) |
| 역학 | 수평 던지기 → 수평 던지기, 사인 곡선 → 선, 스프링 → 코일 |
| 날씨 / 기압과 바람 | 선 두께 → 화살표 |
| 렌즈·거울 | 선 두께 → 모양, 광선 두께 → 광선 |
| 수은주 | 선 두께 → 수조, 선 두께 → 유리관(같은 이름의 행이 둘) |
| 대류 | 선 두께 → 모양, 유리 두께(mm, 실제로 strokeWidth) → 비커 |
| 주기율표 | 선 두께 → 모양 |
| 세포분열 | 상동 염색체 선 두께 → 유전자 좌(염색체 외곽선으로 오해하기 쉬움), 세포 주기 굵기 → 내부 화살표 |
| 파동의 간섭 | 선 두께 → 선·색·표시 |
| 먹이 사슬 | 선 두께 → 화살표 |
| 힘 화살표 | 선 두께 → 모양 |

그 밖에 개체 패널 안에 두께 행이 있는 스크립트는 모두 일괄 OK다: DNA 모형, J자관·U자관, 결정 구조(다이아몬드), 계기 눈금, 단계 흐름도, 달 위상, 무늬 채움, 빛의 반사와 굴절, 순환·배설, 오브젝트 전선, 입자 상태 모형, 전기, 중합체 만들기, 확장 화살표, 스펙트럼. 단, 전자기 유도의 "굵기"만 단위가 mm다.

## 5. 이름이 내용과 다른 행

- "그래프"인데 그래프가 없는 탭: 공통수학 벤다이어그램(테두리), 기하 공간도형(도형), 중학교 수학 전개도(바깥선)·수형도(가지), 수학1 단위원·삼각형·수열, 확률과 통계 경우의 수·확률 수형도(가지).
- 기하 / 공간도형: "축"이 실제로는 평면 평행사변형이다.
- 중학교 수학 / 전개도: "보조선"이 실제로는 접는 선이다.
