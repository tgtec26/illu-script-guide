# 규산염 사면체 모형 설계

## 목표

`스크립트/01_도형/Object_SilicateStructure.jsx`에 「표현 방식」 옵션을 더한다. 기존 원자 모형(산소·규소 원)에 더해,
교과서식 사면체 모형(삼각형 하나를 세 면으로 나눠 음영을 달리 하고 꼭짓점과 가운데에 산소 원을 얹는 그림)을 그린다.
탭이 아니라 다이얼로그 맨 위 라디오로 고른다. 광물·Si 수·방향·위치·미리보기·3D 조명은 두 모형이 공유한다.

## UI

- 맨 위 「표현 방식」 패널: `원자 모형`(기본, 현재 동작) / `사면체 모형` 라디오.
- 크기 패널 행은 모형에 따라 보이고 숨긴다(`visible` + `dlg.layout.layout(true)`).
  - 원자 모형: 산소 지름 · 규소 지름 · 산소 간격 (기존)
  - 사면체 모형: 삼각형 한 변(mm, 기본 6, 1~30) · 산소 지름(mm, 기본 1.5, 0.3~10, 원자 모형 값과 별도 저장)
- 음영 패널: 산소 K는 공유. 규소 K는 원자 모형만. 면 음영 K(기본 60, 0~100)는 사면체 모형만.
  「산소 3D 조명 효과」 체크는 공유.
- 위치 패널·미리보기·확인·취소는 그대로.

## 기하

- `buildLayout()`의 카고메 격자를 그대로 쓴다. 사면체 하나 = 격자 삼각형의 변 중점 3개(꼭짓점, 이웃과 공유)
  + 무게중심(위로 솟은 산소). `addTetrahedron`이 꼭짓점 3개를 사면체별로 추가 기록한다.
- 산소 중심 간 거리 `step`: 원자 모형은 산소 지름 + 간격, 사면체 모형은 삼각형 한 변.
- 세로 방향은 기존처럼 90° 회전. 사면체 꼭짓점도 함께 돌린다.
- 화면 중앙 정렬은 기존 `centerShift` 그대로(꼭짓점 = 격자점이므로 경계 상자가 같다).

## 면 음영 규칙

- 안쪽 삼각형 3개 = (꼭짓점 i, 꼭짓점 j, 무게중심).
- 빛 방향은 화면 기준 135°(왼쪽 위). 산소 3D 조명 하이라이트(중심에서 −0.35r, +0.35r)와 같은 방향이다.
- 면마다 바깥 방향 = 무게중심 → 바깥 변 중점. 빛 방향과의 내적이 큰 순서로 밝음 · 중간 · 어둠.
- 결과: 위로 뾰족한 삼각형은 왼쪽 → 오른쪽 → 아래, 아래로 뾰족한 삼각형은 위 → 왼쪽 → 오른쪽 순으로 어두워진다.
  세로 방향(90° 회전)에서도 세 면의 내적이 모두 달라 톤이 겹치지 않는다.
- 톤: 어두운 면 = 면 음영 K, 중간 = 2/3, 밝음 = 1/3 (60 → 20 / 40 / 60).

## 그리기

1. 사면체마다 안쪽 삼각형 3개. 선 0.3pt K100(산소 원과 같은 선), 면은 위 톤.
2. 공유 꼭짓점 산소 원(중복 없이 한 번씩).
3. 가운데 산소 원.
4. 규소는 그리지 않는다.

산소 원은 기존 `drawOxygen`을 그대로 써서 K 채움과 3D 조명(방사형 그라데이션 클리핑)을 공유한다.
결과 그룹 이름은 `Silicate tetra <mineral>`.
