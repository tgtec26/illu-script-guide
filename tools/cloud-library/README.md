# 구름 라이브러리 생성 도구

`스크립트/01_도형/Object_Cloud_library.jsxinc`를 다시 만드는 Node 스크립트. 원본은 사용자가 일러스트레이터에서
아트보드마다 구름 하나씩 그린 `.ai`(PDF 호환 저장) 파일이다. 저장소에는 넣지 않는다
(2026-09 기준 `G:\내 드라이브\01_그림 영상 자료\03_중학교 3학년\02_날씨와 기후변화\여러 가지 구름.ai`, 아트보드 9개).

1. `node ai-extract.js <file.ai> <extract.json>` — PDF 콘텐츠 스트림(객체 스트림 포함, 모든 페이지)을 풀어 채움·획 패스와 색, 획 두께를 뽑는다.
2. `node pages-lib.js <extract.json> <out.jsxinc> [sheet.svg]` — 페이지 = 구름 하나로 보고 역할을 색으로 정해 높이 1로 정규화한다.
   채움 K0 = 구름, K20 = 그림자 1, K40 = 그림자 2, 채움 K100(윤곽선을 면으로 만든 링) = 외곽선(바깥 고리를 0.3pt 획으로),
   획 K100 = 선(0.3pt로 통일). 다른 색은 버리고 목록에 찍는다.

원본 파일에서 지켜야 할 것: 아트보드 하나에 구름 하나, 면 색은 위 K값만, 선은 K100.
구름 이름은 `.jsxinc`의 `name`을 손으로 고치거나 pages-lib.js에서 정한다.
